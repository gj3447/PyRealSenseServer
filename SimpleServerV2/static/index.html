컬러 스트림 (JPEG)

GET /color_jpeg
JPEG 압축된 컬러 이미지를 반환합니다. 웹 표시나 네트워크 전송에 최적화되어 있습니다.

깊이 스트림 (JPEG)

GET /depth_jpeg
깊이 데이터를 컬러맵으로 시각화하여 JPEG로 반환합니다. 최대 6m 범위를 JET 컬러맵으로 표현합니다.

컬러 스트림 (원본)

GET /color_raw
원본 BGR8 컬러 이미지 데이터를 반환합니다. 무손실 원본 데이터가 필요한 경우 사용하세요.

GET /depth_raw
원본 Z16 깊이 데이터를 반환합니다. 정밀한 깊이 측정이 필요한 경우 사용하세요.

카메라 캘리브레이션

GET /camera/calibration
카메라의 모든 캘리브레이션 파라미터를 반환합니다. 컬러/깊이 카메라의 intrinsics와 extrinsics 정보가 포함됩니다.
형식: JSON | 업데이트: 고정값

카메라 설정

GET /camera/config
현재 카메라의 설정 정보를 반환합니다. 해상도, 프레임레이트, FOV 등 상세 정보가 포함됩니다.
형식: JSON | 실시간 업데이트

현재 카메라 정보

GET /camera/current_info
현재 카메라 상태와 실시간 프레임 정보를 반환합니다. 해상도, FPS, 프레임 번호 등 실시간 데이터가 포함됩니다.
형식: JSON | 실시간 업데이트 | 자동 새로고침
